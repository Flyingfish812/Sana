L1 Pipeline Summary (entry: run_l1_pipeline)

1) 输入与初始化
- 入口函数: run_l1_pipeline(config)
- 读取 dataset_id、reader、split、normalization、artifacts_dir 等配置。
- 创建产物目录: artifacts/<dataset_id>/L1

2) Reader 构建与数据探测
- 根据 reader.kind 调用 build_reader(kind, **reader_cfg)
  - h5 -> H5Reader
  - nc -> NCReader
  - mat/sst -> MatReader
- 调用 reader.probe() 获取 shape5d 与 DataMeta

3) 数据划分（不读取全量数组前先做 index 规划）
- 从 split 配置取 strategy/unit/ratios/seed
- 调用 split_indices(shape5d, strategy, unit, ratios, seed)
- 输出 train/val/test 索引（frame 或 sequence）

4) 读取完整 5D 数据数组
- 调用 reader.read_array5d() 获取 array5d，布局固定为 [N,T,H,W,C]

5) 训练集统计量计算
- 调用 compute_train_stats(array5d, splits['train'], unit, method)
- frame/sequence 都使用流式聚合（不构造 [M,H,W,C] 大数组）
- method 支持 zscore/minmax
- 输出通道级 mean/std 或 min/max/scale

6) 全量归一化与产物冻结
- 使用训练统计量按通道归一化（zscore/minmax）
- 使用 open_memmap 分块写入 array5d_norm.npy，避免全量中间数组峰值

7) L1 产物写入
- 归一化数组: artifacts/<dataset_id>/L1/array5d_norm.npy
- split 索引: artifacts/<dataset_id>/L1/splits/{train,val,test}.npy
- 元数据: artifacts/<dataset_id>/L1/manifest.json
- 统计量: artifacts/<dataset_id>/L1/stats_train.json

8) 返回摘要
- 返回 L1Summary:
  - dataset_id
  - shape5d
  - split_sizes
  - stats_method
  - artifacts_dir

关键约束
- 统一数据布局为 NTHWC
- L1 只冻结一个标准化后的完整数组，不保存 train/val/test 子数组
- 官方下游入口：load_l1_array_and_splits / build_dataloaders_from_l1
- L2/L3/L4 禁止回退调用 build_reader/read_array5d
